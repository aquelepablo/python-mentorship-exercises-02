# Project Structure

This document describes the main files and directories in this repository, considering the project scope documented up to exercise `e05`.

## Root Directory

- **README.md**: main project documentation with context, setup, and execution examples.
- **PROJECT_STRUCTURE.md**: reference file describing the repository layout.
- **main.py**: simple entry point with a menu to execute exercises `e01` to `e05`.
- **e01_task_list_manager.py**: manages task insertion with duplicate validation using a list.
- **e02_login_with_tuple.py**: simulates a basic login flow using tuple-based credentials.
- **e03_vip_club_checker.py**: validates VIP access using a set of allowed guests.
- **e04_grade_classifier_dict.py**: classifies a subject status based on values stored in a dictionary.
- **e05_data_sentinel_protocol.py**: simulates a secure access validation flow combining sets, tuples, dictionaries, and conditional rules.
- **pyproject.toml**: Python project configuration.
- **uv.lock**: dependency lock file generated by `uv`.
- **.python-version**: defines the Python version used locally.
- **.gitignore**: lists files and directories ignored by Git.

## Directories

- **.venv/**: local virtual environment.
- **.git/**: internal Git repository data.

## Organization Notes

This repository follows a simple rule: exercise files stay in the root when they are part of the same list and benefit from quick access.

The current documentation scope intentionally covers only exercises `e01` to `e05`, even though additional files may already be present in the repository.
